\section{Conclusion}
\label{sec:conclusion}

We specified, implemented, and unit-tested against hand-computed
masks an evaluation stack that does not quietly pick the wrong F1, the
wrong ECE, or the wrong corruption (both frames). The remaining work
is running it on trained models with budgeted GPU hours and filling
the tables in \S\ref{sec:results}. The system is a reviewer aid, not a
production decision tool.
